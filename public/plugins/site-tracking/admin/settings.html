Mesure d’audience sans consentement (Matomo)

Le tag Matomo est émis sans cookie (disableCookies) : configuration exemptée de consentement par la CNIL. Renseignez l’adresse de votre instance Matomo et l’identifiant du site.

Déclenché à chaque demande envoyée.
Scripts chargés sur toutes les pages, sans consentement

Uniquement des outils exemptés (mesure d’audience sans cookie). Collé tel quel dans le <head>.

Tags marketing, chargés après consentement

Google Tag Manager, Google Ads, Meta, LinkedIn… Collez les extraits fournis par ces plateformes. Ils restent inertes tant que le visiteur n’a pas accepté dans le bandeau ; le choix est conservé six mois. Dès qu’un extrait est présent, le bandeau s’affiche et le lien « Cookies » du pied de page permet de changer d’avis.

Événements disponibles pour vos tags : document.addEventListener('id:track', e => e.detail) (nom lead à chaque demande envoyée), et dataLayer.push({event: 'id_lead'}) pour GTM.
